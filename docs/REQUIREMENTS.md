## Scope boundaries that remain explicit

No physical hardware is available or claimed. The prompt permits reproducible simulated captures, so physical testing is not a release blocker for the disclosed demo. OCR, arbitrary C++ execution, unsupported KiCad hierarchy/buses/mirroring/diagonal geometry, UART parity and SPI word widths other than eight are outside the initially supported subset, not hidden features. External provider credentials are optional because the local semantic/extractive workflow is functional; live provider verification must remain unclaimed without credentials.
